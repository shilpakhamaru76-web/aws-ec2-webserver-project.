

# AWS EC2 Web Server Deployment Project

## Project Overview
This project demonstrates the deployment of a
Linux web server using Ubuntu and Nginx.

## Objective
To understand Linux server administration,
web hosting, HTTP requests, SSH and deployment.

## Technologies Used
- Ubuntu Linux
- Nginx
- HTML and CSS
- SSH
- Git
- GitHub

## Project Implementation
1. Installed Ubuntu using WSL2 on Windows.
2. Updated the Linux packages.
3. Installed and started Nginx.
4. Created a custom HTML website.
5. Configured the website directory.
6. Tested the website using localhost.
7. Monitored Nginx access and error logs.

## Website Location
/var/www/html/index.html

## Testing
URL: http://localhost

## Result
Successfully deployed a custom website
using the Nginx web server on Ubuntu Linux.

## Learning Outcomes
- Linux server administration
- Web server configuration
- HTTP and networking basics
- SSH connectivity
- Git and GitHub version control

## Future Improvements
- Deploy on AWS EC2
- Configure AWS Security Groups
- Add HTTPS using SSL/TLS
- Automate deployment using Jenkins
